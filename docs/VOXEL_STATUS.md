# Voxel status

Which maps of Hoenn are voxelized, which are finished and which still have
faults, map by map and room by room. It is how contributors coordinate the
voxel work: check here before starting a map, and update it when your work
lands.

> **Under review.** This document was filled in from the code and the
> development notes, and is still being checked map by map: it may still
> contain mistakes. If a row does not match what you see in the game, fix it
> in your pull request.

**This file describes the branch it is in.** Every branch (`main`, `dev`,
`integration` and your working branches) carries its own copy, and each copy
moves with the code of that branch. Update it in the same commit or pull
request that changes the map, never in a separate one, so that merging the
work merges its status too. When two branches disagree on a row, the merge
keeps the one that describes the merged code.

How to voxelize a map: [VOXEL_GUIDE.md](VOXEL_GUIDE.md) and, for mountains,
[VOXEL_MOUNTAINS.md](VOXEL_MOUNTAINS.md).

## How to read and update the tables

One section per town, route, cave or special area. Its first row is the
outside; every interior that can be entered from it follows.

| Column | What goes in it |
|---|---|
| Area | `Exterior`, or the interior's name (floor included) |
| Layout | The layout the map uses. **×N**: N maps share it, so modelling it once covers all of them, and a fault in it shows in all of them |
| Buildings | Buildings and objects (in an interior: the room and its furniture) |
| Terrain | Mountains and relief on terraces. `—`: the map has no mountain to solve |
| Notes | Known faults and what is missing. Coordinates are in cells, `(x,y)` |

Status:

| Mark | Meaning |
|---|---|
| ⬜ | Not started: nothing modelled for this map yet (only the generic trees, signs and ledges) |
| 🟦 | In progress: part of it is modelled (say what is missing in Notes) |
| 🟨 | Modelled, **not reviewed at all**: it has faults still to find and list |
| 🟧 | Has known faults, listed in Notes |
| ✅ | Reviewed in game: finished, no known faults |

Rules:

- Move a row to ✅ only after reviewing the map in game, on a console. Say what you
  checked in the pull request.
- Reviewing a 🟨 row moves it to 🟧 (its faults listed in Notes) or ✅.
- A fault found later sends the row back to 🟧, with the fault in Notes.
- A shared layout (**×N**) has the same status on every row that uses it:
  change them all together.
- Leave rows of maps you have not touched as they are.
- After editing the tables, run `python 3ds_port/scripts/voxel_status.py --write`
  to refresh the Progress block below, and commit it with them.
